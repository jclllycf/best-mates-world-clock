# Best Mates v0.2.0

Best Mates v0.2.0 is the first major interface upgrade after the original public preview.

The attached `BestMates-v0.2.0-debug.apk` is a debug-signed early public build. It is not a Play Store or production-signed APK.

This release moves the main app onto the new Best Mates 2.0 visual system while preserving existing widget projects and editor behavior.

Highlights:

- redesigned Workspace
- new Settings interface
- upgraded Editor and Inspector
- unified Crystal pickers and dialogs
- improved rotated-object dragging
- refreshed themes and Orbit controls
- continued compatibility with existing projects and widgets

This is still an early public release. A larger layout reconstruction, final Sun/Moon artwork, expressive typography and additional polish are planned for future versions.
