# Best Mates

**اللغة:** [English](../README.md) · [中文](README_zh-CN.md) · [Русский](README_ru.md) · [العربية](README_ar.md) · [Türkçe](README_tr.md) · [Deutsch](README_de.md)

Best Mates هو محرّر مفتوح المصدر لويدجتات الوقت العالمي على Android، صُمم لإنشاء ويدجتات شخصية من دون تعلّم محرّر الصيغ.

> **الحالة: v0.2.0.** يمكن استخدام Best Mates كإصدار Android عام مبكر: يعمل محرر الويدجت الأساسي، وانتقلت الواجهة إلى النظام البصري Best Mates 2.0، مع تحسينات مستقبلية للتخطيط والمرئيات والأصول.

## المتاح الآن

- إنشاء مشاريع الويدجت ونسخها وإعادة تسميتها وحذفها.
- حتى 10 مدن و5 طبقات نصية لكل مشروع.
- اختيار القارة ← الدولة ← المدينة أو البحث بالاسم الإنجليزي للمدينة.
- الوقت والتاريخ والدولة ورمز النهار/الليل وفق الشروق والغروب المحليين.
- تعديل الخلفية والمدن والنصوص على لوحة التصميم، مع النقل وتغيير الحجم والتدوير والنسخ واللصق والتثبيت والتراجع والإعادة.
- الإضافة إلى الشاشة الرئيسية في Android مع أحجام معلنة من 1×1 إلى 4×6.
- Workspace مُعاد بناؤه، وSettings مُنقَلة، وعناصر Editor وInspector، ولوحة Soft Atelier، ومنتقيات وحوارات Crystal، وعناصر Orbit Charm.
- هويات Cloud وDream وMidnight وMono مع المظهر الفاتح أو الداكن أو مظهر النظام.
