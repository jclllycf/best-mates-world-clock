# Contributing to Best Mates

Thank you for helping make Best Mates easier and more pleasant to use.

## Report a bug

Open an issue with the app version, phone model, Android version, clear reproduction steps and a screenshot or short recording if possible. Please remove personal information from captures.

## Suggest an improvement

Describe the user goal first, then show the expected result. Visual references are welcome for editor interactions, shapes, solar icons and themes.

## Code contributions

1. Create a branch from the current public version.
2. Keep changes focused on one problem.
3. Build with `./gradlew.bat assembleDebug` before opening a pull request.
4. Explain the behaviour you tested and include a screenshot for visible UI changes.

Best Mates uses Kotlin, Jetpack Compose and Android AppWidget/RemoteViews. Third-party artwork must have a compatible licence and be recorded in the notice file.
